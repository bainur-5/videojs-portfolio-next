Video Player Lab — Variant A / Editorial Lab

Статический макет на HTML, CSS и JavaScript.
Установка npm не требуется.

Страницы:
- index.html — главная
- players.html — каталог плееров
- player.html?id=cinema — страница концепта
- case-study.html — кейс
- about.html — о проекте
- contact.html — контакты

Языки:
- English
- Русский
- Кыргызча

Типографика:
- Noto Serif — заголовки
- Noto Sans — основной интерфейс и текст

Все управляющие элементы используют SVG-иконки. Текстовые знаки оставлены только там, где они являются частью содержания или типографики.
